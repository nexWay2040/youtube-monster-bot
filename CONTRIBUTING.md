# Вклад в проект 🤝

Привет! Проект делают люди — любой вклад полезен, от опечатки в README до новой фичи.

## Быстрый старт для разработки

```bash
git clone https://github.com/nexWay2040/youtube-monster-bot.git
cd youtube-monster-bot
pip install -r requirements.txt
cp .env.example .env        # заполните своими ключами
python bot.py               # консольное меню → [1] запуск
```

## Как предложить изменение

1. **Найдите или создайте [Issue](../../issues)** — особенно для крупных фич: сначала обсудим идею, чтобы ваш труд не пропал.
2. Сделайте форк и ветку: `git checkout -b feature/short-description`.
3. Изменения старайтесь делать маленькими и атомарными.
4. Перед пушем проверьте, что всё запускается:
   ```bash
   python -m py_compile bot.py channel_monitor.py
   python bot.py   # бот должен стартовать и отвечать на /start
   ```
5. Откройте Pull Request с описанием **что** и **зачем**.

## Правила кода

- Python 3.10+, стиль — PEP 8 (разумно, без фанатизма).
- Не коммитьте секреты: `.env`, `*.session`, `cookies.txt` уже в `.gitignore`.
- Новые настройки проекта обязательно добавляйте в `.env.example` с комментарием.
- Комментарии и сообщения коммитов — на русском или английском, как удобнее.

## Куда смотреть, если непонятно

- `bot.py` — ядро: TUI-меню, движок yt-dlp + FFmpeg (Direct Copy), кэш, админка.
- `channel_monitor.py` — отдельный экспериментальный бот автопубликации.
- `README.md` — полное описание возможностей и установки.
