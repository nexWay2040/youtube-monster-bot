## 📌 О проекте

**YouTube Monster Bot** — это высокопроизводительный Telegram-бот коммерческого уровня, спроектированный для обхода любых лимитов мессенджера и видеохостинга. В отличие от большинства публичных ботов, он не режет качество, не требует платных подписок и работает полностью на вашем железе или VPS.

Проект построен на асинхронном движке **Telethon**, **yt-dlp**, **FFmpeg** и **Deno** с использованием ООП-архитектуры и базы данных SQLite3.

## ✨ Уникальные возможности (Ultimate Edition)

### 📚 Динамический загрузчик плейлистов (Batch Downloader)
Бот автоматически распознает плейлисты любой длины и предлагает скачать их пачками.
* Выбор размера пачки прямо в инлайн-меню: **по 1, 3, 5 или 10 видео** одновременно.
* Защита от банов (Staggered Start): пауза в 1.5 секунды между роликами внутри пачки предотвращает ошибки HTTP 403 Forbidden.
* Изоляция ошибок: при удалении одного видео из плейлиста обработка остальных продолжается.

### 🌐 Deno & EJS Integration (Обход JS-челленджей YouTube)
Автоматическое обнаружение и интеграция движка **Deno** (`remote_components: ['ejs:github']`). Бот на лету решает сложные JavaScript-сигнатуры и челлендж-запросы YouTube, предотвращая сбои скачивания в 1080p FHD.

### 🔞 100% Обход возрастных ограничений 18+ (Без файлов)
Импорт авторизованной сессии прямо из локального браузера (`BROWSER_COOKIES=firefox/chrome`). Бот считывает куки на лету, открывая доступ к возрастному или приватным роликам без необходимости экспортировать `cookies.txt`.

### 🧠 Dual-Contour Architecture (Белый список на 4 ГБ)
Гибридная схема на двух клиентах Telethon (`bot_session` + `user_session`):
* Доверенные пользователи из списка `PREMIUM_USERS` получают лимит выгрузки **до 4 ГБ** через юзербот-сессию.
* Обычные пользователи получают лимит **до 2 ГБ** с отправкой через стандартного бота.
* Юзербот работает только в одностороннем режиме отправки и никогда не пишет сторонним людям.

### ⚡ Локальный CDN-кэш (База данных SQLite3)
База данных `monster_bot.db` мгновенно отдаёт ролики повторно.
* Повторный запрос видео подсвечивается кнопкой **`⚡ (Кэш)`**.
* Файл отдается за **0.1 секунды** по Telegram `file_id` без повторного скачивания и нагрузки на проц/сеть.

### 🖥️ Аппаратное ускорение (GPU Transcoding)
Поддержка аппаратных чипов видеокарт для быстрого перекодирования VP9/AV1 в H.264:
* **AMD Radeon (AMF):** `h264_amf` с CQP-сеткой качества.
* **NVIDIA (NVENC):** `h264_nvenc` с VBR-профилями.
* **Intel QuickSync:** `h264_qsv`.
* **Self-Healing:** При любом сбое видеокарты бот автоматически откатывается на CPU (`libx264`) и успешно доставляет файл.

### 🚀 Direct Copy & Zero-RAM Upload
* **Direct Copy:** Если YouTube отдает поток `H.264 + AAC`, перекодирование пропускается (перепаковка за 1.5 секунды).
* **Zero-RAM Upload:** Потоковый загрузчик разбивает файлы на чанки по 512 КБ в 8 асинхронных потоков. Потребление ОЗУ зафиксировано на уровне **~4 МБ** даже на роликах объемом 4 ГБ.

### 👑 Панель Администратора
Команды управления внутри Telegram:
* `/admin` — Глобальная статистика (юзеры, трафик в ГБ, кэшированные файлы).
* `/users` — Список последних пользователей и их статусы.
* `/ban <ID>` / `/unban <ID>` — Блокировка и разблокировка.
* `/broadcast <Текст>` — Массовая рассылка всем пользователям бота.

## 🇷🇺 Специфика работы в РФ (Обход блокировок)

Бот адаптирован для работы в условиях сетевых ограничений:

### Вариант 1. Запуск через Happ (Локальный прокси SOCKS5)
Если вы используете **Happ**, откройте его настройки и включите опцию **«Allow LAN»**. 
Затем выберите пункт `[4]` в TUI-меню бота или укажите в `.env`:
```env
USE_PROXY=True
PROXY_HOST=127.0.0.1
PROXY_PORT=10808
```
Весь трафик бота пойдет через зашифрованный VPN-туннель Happ.

### Вариант 2. Хостинг на зарубежном VPS (Идеально для 24/7)
Арендуйте дешевый Linux-сервер (Ubuntu) в Европе. На зарубежных VPS блокировки отсутствуют, а скорость канала достигает 1 Гбит/с. Выставьте `USE_PROXY=False` и `VIDEO_ENCODER=libx264`.

## 📥 Установка и запуск

**1. Клонирование репозитория и установка зависимостей:**
```bash
git clone https://github.com/nexWay2040/youtube-monster-bot.git
cd youtube-monster-bot
pip install telethon yt-dlp[default] cryptg PySocks python-dotenv
```

> ⚠️ **Важно:** Убедитесь, что в вашей системе установлены **FFmpeg** и **Deno** (для Deno достаточно выполнить `irm https://deno.land/install.ps1 | iex` на Windows или `curl -fsSL https://deno.land/install.sh | sh` на Linux).

**2. Настройка файла конфигурации (.env):**
Создайте файл `.env` в корневой папке проекта:

```env
# --- НАСТРОЙКИ TELEGRAM API ---
API_ID=123456
API_HASH=your_api_hash_here
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# --- НАСТРОЙКИ СИСТЕМЫ И КОДЕКОВ ---
DOWNLOAD_DIR=./downloads
# Варианты кодеков: libx264, h264_amf, h264_nvenc, h264_qsv
VIDEO_ENCODER=libx264

# Укажите браузер для обхода 18+ (firefox, chrome, edge, yandex)
BROWSER_COOKIES=firefox
DEFAULT_BATCH_SIZE=3

# --- БЕЛЫЙ СПИСОК PREMIUM (4 ГБ) ---
PREMIUM_USERS=123456789,987654321

# --- НАСТРОЙКИ ПРОКСИ (HAPP / VPN) ---
USE_PROXY=False
PROXY_HOST=127.0.0.1
PROXY_PORT=10808
```

**3. Запуск приложения:**
```bash
python bot.py
```
В открывшемся консольном меню выберите:
* `[2]` — для однократной авторизации Premium-юзербота (потребуется ввести номер телефона для выгрузки файлов до 4 ГБ).
* `[1]` — для старта сервера бота.
