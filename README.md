## ✨ Ключевые возможности

* ⚡ **Direct Copy движок:** видео и звук просто перепаковываются в MP4-контейнер без перекодирования картинки — скачивание занимает 1-2 секунды после закачки потока, не грузит ни CPU, ни GPU, и не теряет ни капли исходного качества.
* 🌐 **Мультиязычная озвучка (оригинал / RU / EN):** выбор дорожки прямо в чате, для каналов с официальным дубляжом (**MrBeast**, **Mark Rober** и др.). Раздельный кэш по дорожкам — бот никогда не перепутает озвучку при повторной выдаче.
* 🤖 **Нейросетевая русская озвучка (Yandex AI):** если у видео нет русской дорожки — бот сам прогоняет оригинал через переводчик Yandex и сводит русский звук с видео через Direct Copy, без пережатия картинки.
* 🍪 **Умная система cookies:** приоритет — свежий файл (`cookies.txt`), при устаревании — автоматический переход на куки из браузера (`BROWSER_COOKIES`), с локальным кэшем извлечения и защитой от повреждения файла при параллельных запросах. Фоновая проверка раз в несколько часов шлёт владельцу уведомление в Telegram, если куки перестали работать.
* 🔄 **Автопроверка версии yt-dlp:** раз в сутки бот сверяет установленную версию с последней на PyPI и предупреждает в Telegram, если пора обновляться — YouTube часто меняет защиту, и старая версия быстро перестаёт работать.
* ⚡ **Локальный кэш V2 (`bot.db`):** отдача за 0.1 секунды без повторного скачивания. В панели `/cache` доступен предпросмотр (`🎬 Отправить` файл себе в чат для проверки) и удаление с очисткой диска.
* 👑 **Многоуровневая админка с валидацией:** Владелец + Администраторы. При вводе `/addadmin @username` бот запрашивает Telegram API и проверяет, реальный ли это человек (отсекает ботов и каналы).
* 🛑 **Мгновенная отмена:** кнопка `[ ❌ Отменить ]` на этапах скачивания и загрузки, с очисткой временных файлов.
* 💎 **Dual-Contour (4 ГБ):** гибрид бота и юзербота — пользователи из белого списка получают файлы размером до 4 ГБ вместо стандартных 2 ГБ.
* 🗂️ **Ротация логов:** `bot.log` не растёт бесконечно — автоматическая ротация по 5 МБ, хранится до 5 архивов.

## 💻 Установка через терминал (Miniconda)

### 1. Установка Miniconda в терминале

* **Windows (PowerShell):**
  ```powershell
  winget install Anaconda.Miniconda3
  ```
  *(Либо скачайте установщик через curl: `curl -o miniconda.exe https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe; .\miniconda.exe /S`)*

* **Linux (Bash):**
  ```bash
  curl -fsSL https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -o miniconda.sh
  bash miniconda.sh -b -u -p ~/miniconda3
  ~/miniconda3/bin/conda init bash && source ~/.bashrc
  ```

---

### 2. Развертывание окружения и запуск

```bash
# 1. Клонируем проект и переходим в папку
git clone https://github.com/nexWay2040/youtube-monster-bot.git
cd youtube-monster-bot

# 2. Создаем изолированное окружение Python 3.11 и активируем его
conda create -n monster python=3.11 -y
conda activate monster

# 3. Ставим системный FFmpeg через conda (работает сразу без настройки PATH)
conda install -c conda-forge ffmpeg -y

# 4. Устанавливаем зависимости из requirements.txt
pip install -r requirements.txt

# 5. Создаем рабочий конфиг из готового образца
# На Windows:
copy .env.example .env
# На Linux:
cp .env.example .env
```

> ⚙️ **Настройка:** Откройте созданный файл `.env` и впишите свои `API_ID`, `API_HASH`, `BOT_TOKEN` и `OWNER_ID`. Все параметры и ключи подробно описаны внутри образца `.env.example`.

## 🍪 Про cookies (важно)

YouTube периодически требует подтверждение "я не бот" для некоторых видео (возрастные ограничения, приватность, региональные блокировки). Бот поддерживает два источника, с автоматическим приоритетом:

1. **Файл** (`www.youtube.com_cookies.txt` / `cookies.txt` / путь из `COOKIE_FILE`) — используется, пока не устарел (`COOKIE_MAX_AGE_HOURS` в `.env`, по умолчанию 12 часов).
2. **Браузер** (`BROWSER_COOKIES=edge` / `chrome` / `firefox` в `.env`) — берётся автоматически, когда файл устарел или отсутствует.

⚠️ На Windows чтение живых cookies из **Chrome/Edge** иногда упирается в `PermissionError` (браузер держит файл базы данных занятым даже в фоне). Если сталкиваетесь с этим — либо отключите фоновые процессы браузера в его настройках, либо экспортируйте `cookies.txt` через расширение вроде *Get cookies.txt LOCALLY* и кладите его рядом с `bot.py`.

## 🧪 Экспериментально: автопубликация в канал

Помимо основного бота-загрузчика, в проекте есть отдельный, необязательный скрипт `channel_monitor.py` — он мониторит список YouTube-каналов и сам публикует новые ролики в Telegram-канал (с хештегами автора и базовым определением игры/жанра по названию). Управляется прямо в Telegram через `/menu`, запускается отдельным процессом и **не является основной функцией проекта** — это дополнительная автоматизация поверх движка скачивания `bot.py`, находится в разработке и может вести себя не идеально на нестандартном контенте.
