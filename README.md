## 📌 О проекте

**YouTube Monster Bot** — это высокопроизводительный Telegram-бот коммерческого уровня, спроектированный для обхода любых лимитов мессенджера и видеохостинга. В отличие от большинства публичных ботов, он не режет качество, не требует платных подписок и работает полностью на вашем железе или VPS.

Проект построен на связке **Telethon**, **yt-dlp** и **FFmpeg** с использованием асинхронного ООП-подхода и локальной базы данных SQLite3.

## ✨ Уникальные возможности (Ultimate Edition)

### 📚 Интеллектуальные Плейлисты (Batch Downloader)
Бот автоматически распознает плейлисты и предлагает скачать их пачками.
* Интерактивный выбор размера пачки (по 1, 3, 5 или 10 видео одновременно).
* Встроенная задержка (Staggered Start) для защиты от блокировок YouTube (HTTP 403 Forbidden).
* Изоляция ошибок: если одно видео удалено, скачивание остального плейлиста продолжается без прерываний.

### 🔞 100% Обход возрастных ограничений 18+ (Без файлов)
Бот умеет «на лету» импортировать вашу сессию прямо из браузера (рекомендуется **Firefox**). Забудьте про экспорт `cookies.txt`! Просто авторизуйтесь на YouTube в браузере, укажите его в настройках, и бот получит доступ к любому контенту 18+.

### 🧠 Dual-Contour Architecture (Белый список на 4 ГБ)
Обход жесткого лимита Telegram Bot API в 2 ГБ через использование вашей личной Premium-сессии.
* В `.env` встроен **Белый список (`PREMIUM_USERS`)**.
* Доверенные пользователи получают лимит **до 4 ГБ**, и видео выгружается через ваш Premium-аккаунт.
* Обычные пользователи получают лимит **до 2 ГБ**, и видео загружается стандартным ботом. 
* Ваши личные данные в полной безопасности: юзербот никогда не напишет незнакомцам.

### ⚡ Локальный CDN-кэш (База данных SQLite)
Бот запоминает каждое скачанное видео.
* Если кто-то запрашивает ролик, который уже есть в базе, на инлайн-кнопке появляется значок молнии **`⚡ (Кэш)`**.
* Бот не тратит трафик и мощность видеокарты — он мгновенно отдает файл по `file_id` за **0.1 секунды**!

### 🖥️ Аппаратное ускорение (Hardware GPU Encoding)
Полная поддержка аппаратных чипов видеокарт для сверхбыстрого транскодирования тяжелых кодеков (AV1/VP9):
* **AMD Radeon (AMF):** Сверхстабильная сетка качества CQP.
* **NVIDIA (NVENC) / Intel (QSV):** Профили VBR.
* **Self-Healing:** Если видеокарта дает сбой, бот бесшумно откатывается на программный кодек (CPU `libx264`) и всё равно доставляет видео пользователю.

### 🚀 Direct Copy Mode
Если YouTube отдает поток в формате `H.264 + AAC`, бот пропускает перекодирование и выполняет мгновенную перепаковку за 1.5 секунды с нулевой нагрузкой на процессор.

### 🛡️ Потоковый загрузчик (Zero-RAM Upload)
Инновационная асинхронная очередь `fast_upload`. Файлы разбиваются на чанки по 512 КБ и выгружаются в 8 потоков. Расход оперативной памяти жестко зафиксирован на уровне **~4 МБ** даже при выгрузке огромных 4-гигабайтных фильмов.

### 👑 Панель Администратора и TUI
* **В Telegram:** Команды `/admin`, `/users`, `/ban`, `/unban`, `/broadcast` (массовая рассылка).
* **В консоли (TUI):** Интерактивное меню при запуске для быстрой смены кодеков, настройки пачек плейлиста и прокси без редактирования кода.

## 🇷🇺 Специфика работы в РФ (Обход блокировок)

Бот поддерживает гибкую настройку под любые реалии блокировок:

### Вариант 1. Запуск на домашнем ПК (Бесплатно, без VPN)
Используйте утилиты **GoodbyeDPI** или **Zapret**. Они разблокируют YouTube и Telegram на уровне сетевых пакетов. В `.env` укажите `USE_PROXY=False`.

### Вариант 2. Запуск через Happ / Hiddify (Локальный прокси)
Если вы используете Hiddify, зайдите в его настройки и включите **«Allow LAN»**. 
Затем укажите в `.env`:
```env
USE_PROXY=True
PROXY_HOST=127.0.0.1
PROXY_PORT=10808
```

Весь трафик бота пойдет через ваш зашифрованный VPN-туннель.

### Вариант 3. Хостинг на зарубежном VPS (Идеально для 24/7)
Арендуйте дешевый Linux-сервер (Ubuntu) в Европе. Там нет блокировок, и скорость канала достигает 1 Гбит/с. Выставьте `USE_PROXY=False` и `VIDEO_ENCODER=libx264`.

## 📥 Установка и запуск

**1. Клонирование и зависимости:**
```bash
git clone https://github.com/USERNAME/youtube-monster-bot.git
cd youtube-monster-bot
pip install -r requirements.txt
```

**2. Настройка (.env):**
Создайте файл `.env` (или скопируйте `cp .env.example .env`) и заполните ваши данные:

```env
# --- НАСТРОЙКИ АВТОРИЗАЦИИ TELEGRAM ---
# Получите API_ID и API_HASH на my.telegram.org, а BOT_TOKEN у @BotFather
API_ID=123456
API_HASH=your_api_hash_here
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# --- НАСТРОЙКИ СИСТЕМЫ ---
DOWNLOAD_DIR=./downloads
# Кодеки: h264_amf, h264_nvenc, h264_qsv, libx264
VIDEO_ENCODER=libx264

# Укажите ваш браузер (firefox, chrome, edge, yandex) для обхода 18+ видео
BROWSER_COOKIES=firefox
# Размер пачки плейлиста по умолчанию (1, 3, 5 или 10)
DEFAULT_BATCH_SIZE=3

# --- БЕЛЫЙ СПИСОК PREMIUM (4 ГБ) ---
# Укажите через запятую Telegram ID пользователей, которым разрешен лимит до 4 ГБ.
PREMIUM_USERS=123456789,987654321

# --- НАСТРОЙКИ ПРОКСИ (ДЛЯ РФ) ---
USE_PROXY=False
PROXY_HOST=127.0.0.1
PROXY_PORT=10808
```

**3. Запуск:**
```bash
python bot.py
```

При запуске откроется интерактивное консольное меню. Выберите `[2]` для авторизации Premium-сессии (если нужна выгрузка до 4 ГБ) или `[1]` для немедленного старта сервера.
