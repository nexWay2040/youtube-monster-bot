## 📌 О проекте

**YouTube Monster Bot** — это высокопроизводительный инструмент нового поколения, созданный для скачивания медиаконтента с YouTube без потери качества и с обходом любых системных лимитов [2].

Проект построен вокруг современных асинхронных технологий:
- ⚡ **Telethon** — прямая работа с протоколом Telegram MTProto [2]
- 🎬 **yt-dlp** — извлечение медиапотоков и автообход 18+ ограничений [1, 2]
- 🛠️ **FFmpeg + Hardware API** — транскодирование на видеокартах (AMD AMF, NVIDIA NVENC, Intel QSV) [1, 2]
- 🗄️ **SQLite3** — локальная база данных, статистика и мгновенный CDN-кэш [2]

## ✨ Ключевые возможности

### 📚 Скачивание плейлистов пачками (Batch Processing)
* Автоматическое обнаружение ссылки на плейлист [2].
* **Двухшаговое инлайн-меню:** выбор качества для всего плейлиста в 1 клик $\rightarrow$ выбор размера пачки (по **1**, **3**, **5** или **10** видео одновременно) [1, 2].
* Защита от `HTTP 403 Forbidden` благодаря паузам-задержкам между стартом роликов в пачке [2].
* Изоляция ошибок: если ролик удален на YouTube, бот пропустит его и продолжит скачивание остальных [1, 2].

### ⚡ Мгновенный CDN-кэш (SQLite3)
* Бот сохраняет `file_id` скачанных роликов до 2 ГБ в базу данных [2].
* Повторные запросы на один и тот же ролик отдаются **за 0.1 секунды** без повторного скачивания и нагрузки на железо [2].
* На кнопках качества автоматически показывается индикатор **`⚡ 1080p (Кэш)`** [2].

### 🔞 Автоматический обход 18+ (Без браузеров и файлов)
* Встроенная поддержка EJS-решателей через Deno (`remote_components`) [1, 2].
* Эмуляция клиентов `android`, `ios` и `mweb`, позволяющая качать ролики с возрастными ограничениями [1, 2].

### 🚀 Direct Copy Mode (Мгновенная упаковка)
Если YouTube предоставляет готовый поток `H.264 + AAC`, бот за 1-2 секунды перепаковывает его без нагрузки на процессор и без потери качества [1, 2].

## 🧠 Dual-Contour Architecture (Двойной контур)
Уникальная система отправки, обходящая стандарный лимит ботов в 2 ГБ [1, 2].

```text
                 Пользователь
                     │
                     ▼
           [ Telegram Bot Interface ]
                     │
        ┌────────────┴────────────┐
        ▼                         ▼
   [ Bot API ]             [ Premium Userbot ]
(Файлы до 2 ГБ)             (Файлы от 2 до 4 ГБ)
```

* **Файлы до 2 ГБ:** прилетают от имени бота (слева) [2].
* **Файлы от 2 до 4 ГБ:** прилетают от имени вашего Premium-аккаунта (справа) прямо в то же окно чата [1, 2]!
* **Белый список (`PREMIUM_USERS`):** запуск 4 ГБ контура разрешен только владельцу и доверенным пользователям в `.env` [2, 3].

---

## 🛡️ Потоковый загрузчик Zero-RAM
Специальный асинхронный загрузчик файлов в Telegram [2]:
* Читает и отправляет файл частями по 512 КБ в 8 параллельных потоков [2].
* Потребляет всего **~4 МБ оперативной памяти** в каждый момент времени [2].
* Полностью предотвращает падение системы по ошибке `MemoryError` на файлах размером 3.5–4 ГБ [2].

---

## 🖥️ Аппаратное ускорение (Hardware Encoding)
Поддерживаются аппаратные чипы видеокарт с принудительной конвертацией в 8-битный цвет (`yuv420p`) для исключения вылетов 10-битных роликов AV1 [1, 2]:

| Оборудование | Кодек в `.env` | Особенности |
| :--- | :--- | :--- |
| **AMD Radeon** (RX 6000/7000) | `h264_amf` | Сверхстабильный CQP-режим (~600 МБ за 45 мин) [2] |
| **NVIDIA** (GTX/RTX) | `h264_nvenc` | Высокоскоростной VBR-режим [2] |
| **Intel** (QuickSync) | `h264_qsv` | Аппаратный VBR-режим [2] |
| **CPU** (Процессор) | `libx264` | Режим `veryfast` с автооткатом при сбое GPU [1, 2] |

## 👑 Панель Администратора
Полное управление сервером бота из чата Telegram (доступно только владельцу) [2]:

* `/admin` — статистика пользователей, трафика, кэша и состояние видеокадров [2].
* `/users` — выгрузка списка последних 50 пользователей и их Telegram ID [2].
* `/ban <ID>` / `/unban <ID>` — управление черным списком [2].
* `/broadcast <Текст>` — массовая рассылка анонсов по всем пользователям базы [2].

## 🇷🇺 Настройка в РФ и на серверах

### Вариант 1. Запуск на европейском сервере VPS (Рекомендуемый для 24/7)
На серверах за пределами РФ (Нидерланды, Германия) YouTube и Telegram работают напрямую [1, 2].
* В файле `.env` установите:
  ```env
  USE_PROXY=False
  VIDEO_ENCODER=libx264
  ```

---

### Вариант 2. Локальный запуск на ПК в РФ (Через Happ / Hiddify)
Если вы запускаете бота на домашнем компьютере в РФ с включенным Happ [1, 2]:
1. Запустите Happ (Hiddify) с вашим VPN-ключом [2].
2. **ОБЯЗАТЕЛЬНО включите галочку «Allow LAN» (Разрешить локальную сеть)** в настройках Happ [2].
3. В файле `.env` установите [3]:
   ```env
   USE_PROXY=True
   PROXY_HOST=127.0.0.1
   PROXY_PORT=10808
   VIDEO_ENCODER=h264_amf
   ```

## 📥 Установка и запуск

**1. Клонирование и зависимости:**
```bash
git clone https://github.com/nexWay2040/youtube-monster-bot.git
cd youtube-monster-bot
pip install -r requirements.txt
```

**2. Настройка конфигурации (`.env`):**
Создайте файл `.env` на основе `.env.example` [3]:
```env
API_ID=ваш_api_id
API_HASH=ваш_api_hash
BOT_TOKEN=токен_вашего_бота
DOWNLOAD_DIR=./downloads
VIDEO_ENCODER=h264_amf
PREMIUM_USERS=ваш_telegram_id
USE_PROXY=False
```

**3. Интерактивный запуск:**
```bash
python bot.py
```
Откроется стильное консольное меню (TUI), где можно в 1 клик переключать прокси, видеокодеки и режим Premium (4 ГБ) [2].
