# Безопасность 🔒

## Что нельзя выкладывать публично

Этот проект использует **юзербота** — вашу личную Telegram-сессию. Утечка любого
из этих файлов даёт полный доступ к вашему аккаунту Telegram:

| Файл / значение | Что даёт злоумышленнику |
|---|---|
| `user_session.session` (+ `-journal`) | Полный доступ к личному аккаунту Telegram |
| `API_ID` + `API_HASH` + номер телефона | Возможность восстановить сессию |
| `BOT_TOKEN` | Полный контроль над вашим ботом |
| `cookies.txt` от YouTube | Ваш аккаунт Google/YouTube |
| `.env` целиком | Всё перечисленное выше |

Все они уже включены в `.gitignore`. **Никогда не коммитьте их в git.**

## Правила для пользователей бота

- Whitelist на 4 ГБ (`PREMIUM_USERS`) и список админов хранятся в `.env` и базе —
  регулярно проверяйте `/admins` и `/whitelist`.
- `OWNER_ID` задавайте явно: при `OWNER_ID=0` владельцем станет аккаунт юзербота.
- Логи (`bot.log`) могут содержать ID пользователей — не прикрепляйте их к баг-репортам
  без цензуры.

## Сообщить об уязвимости

Если нашли проблему безопасности, пожалуйста, **не создавайте публичный Issue** —
напишите напрямую: откройте приватный контакт через профиль автора репозитория
